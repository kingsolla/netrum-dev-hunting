# Contributing

## How to add your developer profile

1. Fork this repository and clone your fork.
2. Install dependencies: `npm install` (Node.js v18+).
3. Create your folder: `dev/<your-name>-dev/` and add `application.md` inside it, using the template in the README.
4. Commit on a new branch (not on `main`) and open a pull request with a short description of who you are.
5. Wait for review - once merged, your profile is part of the registry.

## Rules

- One profile folder per developer: `dev/<your-name>-dev/`.
- Only add your own profile - do not edit other developers' folders.
- Keep `application.md` factual: name, skills, and links you actually own.
